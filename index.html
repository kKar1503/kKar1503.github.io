Kar's Calendar Bot

A private Telegram assistant used only by its owner, Kar Lok. It is not offered to the public.

Privacy policy

What it accesses: the owner's own Google Calendar events (read, create, update, delete) via the calendar.events scope, only when the owner asks or confirms an action.

How data is used: calendar details are processed to answer the owner's requests. Message text and relevant event details are sent to Anthropic's Claude API to understand requests. Data is stored only on the owner's private server and is never sold, shared, or used for advertising.

Removal: access can be revoked at any time at myaccount.google.com/permissions.
